# Kaliraj M Portfolio

## Files
- `index.html` — website content
- `style.css` — white + light-green responsive design
- `script.js` — mobile navigation
- `assets/Kaliraj_Profile.jpg` — cleaned/straightened profile photo
- `assets/Kaliraj_Resume.pdf` — resume with working download button

## How to change mobile number
1. Open `index.html` in VS Code.
2. Press `Ctrl + F`.
3. Search `7356576968`.
4. Replace the visible number and the phone/WhatsApp links with your new number.
5. Save and refresh.

## How to use locally
Double-click `index.html` to preview the site.

## How to put it online
Recommended beginner route: GitHub + Vercel.
1. Create a GitHub account.
2. Create a new repository named `kaliraj-portfolio`.
3. Upload all files/folders exactly as they are.
4. Import the repository into Vercel.
5. Deploy. Vercel gives you a shareable website URL.
6. Put that URL in LinkedIn, Naukri, resume and job applications.

## Important
The resume button uses a relative path, so keep `assets/Kaliraj_Resume.pdf` in the `assets` folder.
